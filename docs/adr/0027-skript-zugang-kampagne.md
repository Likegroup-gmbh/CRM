# Skript-Zugang gilt für ein Skript oder die ganze Kampagne

Ein Skript-Zugang bleibt ein Link plus Code. `skript_scope` entscheidet, ob er nur
das Skript öffnet, an dem er hängt, oder jedes Skript derselben Kampagne — auch
Skripte, die danach erst geschrieben werden. Bestehende Skript-Zugänge mit
Kampagne stehen auf `kampagne`, dieselben Codes bleiben gültig.

Kein eigener Zugang pro Skript: sonst müsste jeder neue Text neu geteilt werden,
und die Gäste hätten mehrere Codes für dieselbe Produktion.
