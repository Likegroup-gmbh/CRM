# Videoidee bleibt in der Tabelle und bekommt einen zweiten Editor

Die langen Texte einer Videoidee lassen sich in der Konzept-Tabelle schlecht lesen, die Spalten sollen aber stehen bleiben und weiter beschreibbar sein. Der Videoidee-Drawer ist deshalb eine zweite Fläche für dieselben Felder, mit Zurück/Weiter und Autosave, nicht ein Ersatz der Tabelle. Ein fokussiertes Feld wird von der anderen Fläche nicht überschrieben.
