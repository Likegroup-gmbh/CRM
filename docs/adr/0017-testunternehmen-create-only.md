# Testunternehmen ist create-only, nur Admin, nie in den Zahlen

Ein Testunternehmen wird nur beim Anlegen gesetzt und danach eingefroren. Sichtbar ist der Unterbaum nur für `rolle=admin`; Investor-Dashboard, Datenqualität, Berichtsstand und Cashflow lassen ihn auch für Admins aussen vor. Umlegbare Flags würden Historie und Investor-Zahlen schmutzig machen, und „alles durchspielen“ ist hier bewusst kein Mitarbeiter- oder Kunden-Login.
