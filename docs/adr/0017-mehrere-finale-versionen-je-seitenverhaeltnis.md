# Mehrere finale Versionen je Seitenverhältnis, 1:1 neben 9:16 und 4:5

Eine finale Version eines Kooperationsvideos oder einer Story trägt eines der Seitenverhältnisse 9:16, 4:5 oder 1:1. Mehrere finale Versionen desselben Verhältnisses bleiben nebeneinander: Markieren fügt einen weiteren Verweis auf die Feedback-Datei hinzu, Abwählen nimmt nur diesen einen Verweis zurück. Hochladen hängt eine weitere Datei an, statt die bisherige zu ersetzen. Die erste Datei behält ihren Namen; ab der zweiten verhindert ein Index (`_02`, `_03`, …) dass Dropbox die vorherige Datei überschreibt, auch beim Download. In der Kooperationstabelle heißt der Button weiter nur nach dem Seitenverhältnis. Der Still bleibt ein Standbild ohne Verhältnis. Ersetzen auf einen Slot hätte bedeutet, eine zweite gebrauchte Datei erst zu löschen und später neu hochzuladen.
