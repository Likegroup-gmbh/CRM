# Favorit hängt an der Person

Ein Favorit ist die Markierung eines Creators durch genau eine interne Person. Die anderen sehen, wer markiert hat, und können danach filtern. Ein einzelner Stern fürs ganze Team wäre später nur mit einer weiteren Spalte zu trennen, sobald zwei Personen denselben Creator unterschiedlich markieren. Der Favorit an einer Kampagne bleibt eine andere Markierung.
