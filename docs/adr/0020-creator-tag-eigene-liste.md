# Creator-Tag hat eine eigene Liste

Ein Creator-Tag ist ein frei benanntes Merkmal am Creator, aus einer eigenen Liste. Dieselbe Liste wie die Tags einer Kooperation hätte Monat und Jahr an die Person gehängt. Besitz bleibt die Liste der Dinge, die jemand hat, und heißt bewusst nicht Tag. Die eigene Liste lässt sich später nur mit Aufwand in eine der beiden anderen überführen.
